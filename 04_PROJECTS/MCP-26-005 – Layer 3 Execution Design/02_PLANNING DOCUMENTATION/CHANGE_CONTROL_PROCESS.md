# Change Control Process

## Purpose
Ensure any change to Layer 3 execution design is explicit, traceable, and ML1-approved.

## Workflow
1. Propose change with source rule IDs and rationale
2. Assess downstream impact
3. Record in Change Log + Delta Notes
4. ML1 approval before implementation

## Required Fields
- What changed
- Why (rule ID + source artifact)
- Impact on execution
- Approval status
