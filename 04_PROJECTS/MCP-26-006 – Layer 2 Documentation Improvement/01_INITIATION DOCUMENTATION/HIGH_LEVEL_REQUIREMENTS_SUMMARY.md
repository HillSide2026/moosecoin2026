# High-Level Requirements Summary

## R1: Terminology Consistency
All Layer 2 artifacts must use consistent terms for strategy vs playbook.

## R2: Rule Traceability
All actionable statements must map to a rule ID.

## R3: Cross-Artifact Alignment
References across Layer 2 docs must point to the correct current paths.

## R4: Non‑Expansion of Intent
Edits must not introduce new strategy intent.

## R5: Auditability
Every change must be recorded with rationale and source.
