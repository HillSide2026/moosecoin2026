# ORCHESTRATION Directory Specification

## What Goes Here

- Run graphs/workflows (pipelines that call agents)
- Schedules/triggers (daily sweep, weekly audit, release flow)
- Dependency maps (which agent runs after which gate)

## What Does NOT Go Here

- Trading strategy logic
- General reference
