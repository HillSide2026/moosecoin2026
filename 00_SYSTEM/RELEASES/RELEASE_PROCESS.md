# Release Process for /00_SYSTEM

Changes to `/00_SYSTEM` are governed and must include a release note.
Keep the process lightweight and consistent.

## Required Steps

1. Create a release note using `TEMPLATE_RELEASE_NOTE.md` in this folder.
2. Summarize changes, impacted artifacts, and migration notes.
3. Record the version bump for `/00_SYSTEM`.
4. Commit the release note alongside the change set.

## Scope

- Applies to any change inside `/00_SYSTEM`.
- Does not apply to changes elsewhere in the repo unless they alter `/00_SYSTEM`.
