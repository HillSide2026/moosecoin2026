# Glossary
Canonical definitions for terms used across the Second Brain.

---

## ML1
Matthew Levine. The human principal who retains final judgment and authority
over all system decisions. ML1 outranks all other layers.

## ML2
The MooseCoin2026 Second Brain system. ML2 includes all top-level
directories in this repository (`00_SYSTEM` through `10_ARCHIVE`):
- `00_SYSTEM` (governance and system mechanics)
- `01_DOCTRINE` (binding rules and constraints)
- `02_MODELS` (decision engines)
- `03_PROTOCOLS` (operational protocols)
- `04_PROJECTS` (project work records)
- `05_RUNS` (run and execution records)
- `06_OUTPUTS` (human-consumable deliverables)
- `07_REFERENCE` (static references)
- `08_RESEARCH` (exploratory analysis)
- `09_INBOX` (intake and triage)
- `10_ARCHIVE` (historical preservation)
ML2 does not act autonomously; it records and enforces ML1 decisions.

## Trading System
The combined operating system for semi-automated trading:
Trading System = ML2 + Execution Environment (third-party app(s)).

## Second Brain (disambiguation)
- **Second Brain (ML2 / MooseCoin2026):** This system. The canonical,
  local-first system-of-record governed by ML1.
- **Second Brain (External / Iwo Szapar):** An external reference
  architecture. Non-binding. See
  `07_REFERENCE/external_systems/iwo_szapar_second_brain/`.
