# SAA002 Specification

## Identity

- Agent ID: `SAA002`
- Legacy name: `folder-map-drift`
- Type: system-admin agent (proto-agent)
- Runtime source: `.claude/agents/folder-map-drift.md`

## Purpose

Compare declared repository structure (`FOLDER_MAP`) against actual filesystem
state and report drift (new/unmapped, missing, misuse signals).

## Allowed Actions

- Read `FOLDER_MAP`, `SCHEMAS`, and repository directory/file state.
- Compare current state against prior drift reports.
- Write exactly one advisory drift report to `09_INBOX/_AGENT_OUTPUT/`.

## Disallowed Actions

- Rename, move, edit, overwrite, or delete existing files.
- Write outside `09_INBOX/_AGENT_OUTPUT/`.
- Call external systems, APIs, or services.
- Modify folder map or structure directly.

## Inputs

- `00_SYSTEM/FOLDER_MAP.md`
- `00_SYSTEM/SCHEMAS.md`
- Filesystem state (repo tree)
- Prior drift reports in `09_INBOX/_AGENT_OUTPUT/DRIFT_REPORT__*.md`

## Outputs

- Primary report:
  - `09_INBOX/_AGENT_OUTPUT/DRIFT_REPORT__YYYY-MM-DD.md`
- Frontmatter classification:
  - `type: drift_report`
  - `agent: SAA002`
  - `status: draft`
  - `authority.level: none`
  - `audience.scope: ml1_only`

## Prompt/System Instruction Capture

- Hard guardrails: read-only repo, single write target, no mutation, no external
  calls.
- Required analysis: parse map, scan disk, compare, diff since prior run.
- Required report sections: summary, new items, missing items, misuse signals,
  recommendations.
