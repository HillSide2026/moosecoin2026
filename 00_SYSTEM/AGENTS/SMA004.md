# SMA004 Specification

## Identity

- Agent ID: `SMA004`
- Name: Release and Change Control Agent
- Type: system-management agent
- Governance baseline: `00_SYSTEM/AGENTS/SYSTEM_MANAGEMENT_AGENTS.md`

## Purpose

Treat ML2 changes like software releases: detect changes, classify them, and
produce release-note and impact-analysis drafts. This agent does not approve.

## Reads

- Git diff / changed files / latest commit list
- `00_SYSTEM/RELEASES/**`
- `00_SYSTEM/DECISION_LOG.md`
- `01_DOCTRINE/**` (release rules)

## Writes

- `00_SYSTEM/RELEASES/RELEASE_NOTES_<YYYY-MM-DD>_<vX.Y.Z>_DRAFT.md`
- `00_SYSTEM/AUDITS/CHANGE_IMPACT_REPORT_<YYYY-MM-DD>.md`

## Core Checks

- Doctrine edits include version bump, effective date, supersedes chain
- Model changes include version bump and linked change note
- Folder-map changes reflected in `00_SYSTEM/FOLDER_MAP.md`
- Breaking changes detected (renames, moves, deleted references)

## Escalation Trigger

- Unversioned doctrine/model changes
- Silent mutation patterns (edits without release note)
- Conflicts between documentation and actual structure

## Output Format

Reports must include:
- Change summary by directory
- Breaking changes
- Migration notes (what changes for authors)
- Approval checklist for ML1
