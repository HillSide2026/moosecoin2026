# SMA002 Specification

## Identity

- Agent ID: `SMA002`
- Name: Model Governance Agent
- Type: system-management agent
- Governance baseline: `00_SYSTEM/AGENTS/SYSTEM_MANAGEMENT_AGENTS.md`

## Purpose

Maintain quality and consistency of `02_MODELS/` as decision engines
(versioning, structure, provenance). This agent does not evaluate
profitability.

## Reads

- `02_MODELS/**`
- `01_DOCTRINE/**` (constraints + required metadata)
- `00_SYSTEM/DECISION_LOG.md`

## Writes

- `00_SYSTEM/AUDITS/MODEL_GOVERNANCE_REPORT_<YYYY-MM-DD>.md`
- `09_INBOX/MODEL_REMEDIATION_TASKS_<YYYY-MM-DD>.md`
- `02_MODELS/_INDEX.md` (optional; only if allowed by policy)

## Core Checks

- Model metadata present (`id`, `version`, `status`, `effective_date`,
  `supersedes` chain)
- Inputs and outputs defined
- Linked doctrine constraints referenced (risk ceilings, approval requirements)
- Naming conventions and placement compliance
- Duplicated or near-duplicate model logic (flag only; do not merge)

## Escalation Trigger

- Model claims `approved` without ML1 approval record
- Model violates doctrine risk constraints
- Two models compete for same purpose without explicit precedence

## Output Format

Reports must include:
- Model Inventory table (`id`, `version`, `status`, `last_updated`)
- Gaps (missing headers/sections)
- Drift signals (structure changes, undocumented edits)
- ML1 Decisions Needed
